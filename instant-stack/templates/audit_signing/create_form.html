Create Audit Signing

Switches the project's tamper-proof audit chain on. With PLATFORM_MANAGED, IndyKite's key signs every batch, manifest and checkpoint; the public keys are served at /audit/.well-known/jwks.json. Create it, and the event sink, before the activity you want chained: earlier events are never added.

Unique within the project and immutable
Customer-managed keys (GCP KMS, AWS KMS, Azure Key Vault) are accepted by the API but not used for signing yet, so this demo uses the platform key.
