Provision Everything

Builds the whole demo from an empty organization. Each step submits its create form exactly as you would, and saves the same IDs to .env. The steps run in dependency order:

  1. Project, then a wait until its knowledge graph (IKG) is active. This can take 10–15 minutes.
  2. Application and App Agent, with credentials saved as APP_TOKEN.
  3. Audit signing and event sink, then a delivery check of about 30s. These run only when the three PUBSUB_* keys are set. If one fails, the run stops before any data is captured.
  4. Token introspect and MCP server, then a short pause for the agent's permissions.
  5. Captures of nodes and relationships. Transient platform errors are retried; an access denial stops the capture.
  6. KBAC policies, external data resolvers, then each CIQ policy followed by its knowledge query.

Only URL_ENDPOINTS, SA_TOKEN and ORGANIZATION_ID must exist beforehand. With "Skip steps…" checked, any step whose ID is already in .env is skipped, except the sink check, which always runs. A re-run therefore continues where a failed or stopped run ended. Keep this tab open until the run finishes: closing it stops the run. AuthZEN evaluations and CIQ executes keep their own forms.
