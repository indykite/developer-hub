Provision Everything (after the MCP server config)

Replays every create button that follows the five Getting Started configurations, in click order: both captures (nodes + relationships), the KBAC policy, the three external data resolvers, then each CIQ policy immediately followed by its knowledge query — submitting exactly what each individual form would submit and saving the same IDs to .env.

The Project, Application, App Agent, Token Introspect and MCP Server must already exist (create them with the Getting Started cards) — their IDs and tokens are read from .env. Captures on a freshly created project can hit cached permission denials or transient platform errors; the run heals the former by re-saving the agent's permissions and waits out the latter, retrying the idempotent upload. AuthZEN evaluations and CIQ executes keep their own forms.
