Backfill .env from an existing sandbox

For a music sandbox that was created outside this app (Hub console sandbox, scripts, another machine): the Application, App Agent, Token Introspect and MCP Server, all KBAC and CIQ policies, and every knowledge query are looked up by name through the Config API and their IDs saved to .env so this app's forms work against that sandbox. Both the fixed names from data/music_manifest.json and the console sandbox's random-suffixed names (<name>-123456-0, app-123456, …) are recognized. Read-only — nothing is created or modified on the platform.

If you set things up with this app's Getting Started buttons or Provision Everything, you do not need this — those save every ID to .env themselves. Tokens (APP_TOKEN, USER_TOKEN) cannot be recovered — credential secrets are only shown at creation — so they stay as they are. Configs that do not exist in the sandbox are reported as missing. The two capture markers (CAPTURED_NODES, CAPTURED_RELATIONSHIPS) are set to true on the premise the sandbox already holds its data — capture state cannot be read from the Config API.
